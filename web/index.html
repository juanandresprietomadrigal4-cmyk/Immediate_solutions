Información del proyecto

Arquitectura: sensores → ESP32 → API REST → interfaz web.

🌿
Este sistema supervisa temperatura, humedad y calidad del aire en un invernadero. Un ESP32 lee DHT22 y MQ135, expone una API JSON y sirve esta interfaz desde flash. La carpeta web/ es la fuente de la UI; el script tools/build_web_bundle.py genera el HTML embebido para el firmware.
Nombre del proyectoSistema de Monitoreo de Invernadero
PlataformaESP32 (PlatformIO)
API/api/sensors, /api/status, /api/wifi
SensoresDHT22 (GPIO 4) · MQ135 (GPIO 34)
InterfazServidor web en el ESP32
ActualizaciónCada 2 segundos
Desarrollo localpython tools/dev_server.py
EstadoIntegrado hardware + web
